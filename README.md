# battery-health-prediction-ml
# Battery Health Prediction Using Machine Learning

## Project Overview
This project analyses battery capacity degradation using the NASA Battery Aging Dataset. A Linear Regression model is used to estimate battery discharge capacity based on the discharge cycle number.

## Objectives
- Analyse battery discharge capacity over repeated cycles.
- Calculate an estimated State of Health (SOH).
- Train a Linear Regression model.
- Evaluate predictions using MAE, RMSE, and R² score.

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- SciPy
- Scikit-learn

## Methodology
1. Load the NASA battery dataset.
2. Extract discharge-cycle capacity.
3. Calculate SOH relative to the first recorded capacity.
4. Visualise capacity degradation.
5. Train and test a Linear Regression model.
6. Evaluate model performance.

## Results
Results and evaluation metrics are generated by running the notebook. Actual metric values should be added after verifying the output.

## How to Run
1. Open the notebook in Google Colab.
2. Upload or extract the NASA battery dataset.
3. Run all cells.
4. Review the graphs and evaluation metrics.

## Disclaimer
This is an educational project. Predictions beyond the observed cycles may be unreliable and are not intended for safety-critical battery monitoring.
